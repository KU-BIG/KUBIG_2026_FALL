# 6단계 결과 보고서 (시계열분석 — 김 담당: 가전)

작성일: 2026-08-21.

## 1. 설계

- **분석 단위**: 단위1(도메인 전체 월별 집계) + 단위2(30건 이상 리뷰 있는 상품 238개, 전역학습). 원래 필수 티어(단위1)만 있던 데서, 조호평님 피드백을 반영해 **naive baseline(마지막 값 그대로 예측) 대비 MAE 비교를 단위1·단위2 둘 다 추가**했다.
- **타겟 변수**: 단위1은 월별 부정 리뷰 비율(`GeneralPolarity == -1`), 단위2는 상품별 월별 부정비율. 4단계 속성별·5단계 토픽별(98개, `05c_topic_modeling_김.ipynb` 최종본) 언급 추이도 보조 스크리닝으로 확인.
- **방법**: 단위1 — Prophet(추세·변곡점, 통계기법·DL 아님) + DLinear/NLinear(경량 DL) + naive baseline, 최근 6개월 홀드아웃으로 비교. 단위2 — N-BEATS 전역학습(`QuantileRegression`으로 10~90% 확률적 예측) + naive baseline.
- **임베딩/토큰화 재사용 없음**: 6단계는 5단계 결과(토픽)를 스크리닝에만 보조로 쓰고, 시계열 모델 자체는 리뷰 날짜(RDate)·부정비율만 입력으로 쓴다.

## 5. 권장 티어: naive baseline 대비 비교 (조호평님 리뷰 반영)

### 5-1. 단위1 — 도메인 집계

최근 6개월 홀드아웃으로 naive(마지막 값 그대로 예측)와 MAE 비교:

| 모델 | MAE | naive 대비 |
|---|---|---|
| naive(마지막 값 그대로) | 0.0331 | - |
| Prophet | 0.0383 | 못 이김 |
| **DLinear** | **0.0306** (MAPE 31.4%) | **이김** |
| NLinear | 0.0352 (MAPE 37.4%) | 못 이김 |

**DLinear만 naive를 이겼다.** 최근 3개월(2022-09~11) 부정비율이 4.8%→8.1%→11.4%→14.7%로 급격히 튀는 구간이 있어서, 과거 패턴을 학습하는 모델(Prophet·NLinear)일수록 이 급변을 못 따라가고, 오히려 "마지막 값을 그대로 쓰는" naive나 구조가 단순한 DLinear가 상대적으로 덜 틀렸다. 즉 naive를 못 이겼다는 것 자체가 "이 시점에 예측 불가능한 이상 신호가 있었다"는 방증이기도 하다 (3절 변곡점과는 별개로, 관측기간 맨 끝의 급변이라 Prophet 변곡점 탐지에는 아직 안 잡힌 상태).

### 5-2. 단위2 — 상품 단위 전역학습(N-BEATS)

| 모델 | MAE | naive 대비 |
|---|---|---|
| naive(마지막 값 그대로) | 0.1038 | - |
| **N-BEATS(중앙값 q50)** | **0.0974** | **이김** |

238개 상품을 한 모델에 묶어 전역학습한 N-BEATS가 naive를 이겼다 — 상품 하나하나는 짧아서 개별로는 학습이 안 되지만, 여러 상품을 같이 학습시키는 전역학습(darts 멀티시리즈 API)의 이점이 실제로 확인된 결과다.

## 6. 한계 및 다음 단계

- **`가전_breach_products.csv` 재다운로드 필요** — 어떤 상품이 이탈했는지 구체적인 목록이 아직 없어서, 채 팀원처럼 "원문 대조로 진짜 급증인지 확인"하는 단계를 아직 못 했다.
- **롤링 백테스트(historical_forecasts) 미실시** — 지금은 마지막 시점 단일 hold-out만 봤다. 채·조 팀원은 이걸로 재검증까지 했는데, 가전은 아직 단일 hold-out 수준이라 "이 결과가 우연이 아닌지"는 추가 검증이 필요하다.
- 단위1에서 naive를 이긴 모델이 DLinear 하나뿐이라는 점 — 채 팀원 보고서(IT기기)에서도 "DLinear가 naive보다 나빴다"는 정반대 결과가 나왔는데, 가전은 오히려 DLinear만 이기고 NLinear·Prophet이 졌다. 같은 팀 안에서도 도메인마다 어떤 모델이 유리한지 다르게 나온다는 뜻이라, "무조건 이 모델이 낫다"고 일반화하면 안 된다는 근거로 볼 수 있다.
- 다음: csv 재다운로드 후 상승 이탈 상품 원문 대조, 여유 되면 롤링 백테스트 추가.
