# Generation / LLM

This directory contains the generation stage of the Korean financial-news RAG pipeline.

## Files

- `prompt.py`: grounded prompt template. The model is instructed to answer only from retrieved news and cite `[뉴스N]`.
- `llm.py`: provider adapters. `LLMClient` holds the shared behaviour; `ClaudeClient` and `OpenAIChatClient` fill in what differs.
- `router.py`: the search gate — decides per turn whether retrieval is needed.
- `../rag.py`: connects retrieval -> prompt -> LLM -> answer + source metadata.

## Providers

Three are supported, selected with `LLM_PROVIDER`:

| `LLM_PROVIDER` | key | model | notes |
| --- | --- | --- | --- |
| `anthropic` (default) | `ANTHROPIC_API_KEY` | `CLAUDE_MODEL` | defaults to `claude-sonnet-5` |
| `openai` | `OPENAI_API_KEY` | `OPENAI_MODEL` | `OPENAI_BASE_URL` points at a compatible gateway |
| `openrouter` | `OPENROUTER_API_KEY` | `OPENROUTER_MODEL` | base URL is fixed in code |

OpenAI and OpenRouter share one adapter — same wire format, different host. The
two differences that bite are handled per provider: OpenAI proper gets
`max_completion_tokens` (the o-series rejects the deprecated `max_tokens`),
OpenRouter gets `max_tokens`, which it normalises across every model it proxies.

Call sites never name an adapter. `get_llm()` is the single construction point,
so switching providers is an environment change, not a code change.

```python
from generation.llm import get_llm

llm = get_llm()                                  # whatever LLM_PROVIDER says
llm = get_llm(provider="openrouter", model="…")  # or ask for one directly
```

## Setup

From the project root:

```bash
uv sync
uv run python setup_api.py            # interactive: provider, key, model
uv run python setup_api.py --check    # verify the current .env, change nothing
```

The key is verified against the provider's models endpoint before it is written.
That call costs no tokens and returns the models the key can actually reach, so
a typo fails here rather than at the first question. The existing `.env` is
merged line by line — other providers' entries and comments survive.

To set the variables by hand instead, copy `.env.example` and fill in one
provider's rows. Do not commit a real key.

## Run the end-to-end pipeline

Make sure the Chroma index already exists, then:

```bash
uv run python rag.py "삼전 반도체 실적 전망은?"
```

The result is JSON containing:

- `question`
- `answer`
- `sources` (`news_number`, title, date, URL, stock names, similarity)

The source list is built from the retrieval results rather than generated by the
model, so the displayed URLs remain tied to the actual retrieved chunks.
